# CivilHub

## Overview

CivilHub is a full-stack application starter with a TypeScript Express API and a React + Vite client.

## Stack

- Backend: Node.js, TypeScript, Express, Mongoose
- Frontend: React, Vite, TypeScript, Tailwind CSS

## Getting Started

1. Install dependencies in the server and client folders.
2. Copy `.env.example` to `.env` in the server and fill in your config.
3. Run the server and client separately for local development.
